# Student Score Analyser

A data analysis project that generates and analyses exam scores for 100 students across 5 subjects using NumPy and Matplotlib.

## Features
- Generates realistic student score data using NumPy
- Computes statistics — mean, median, std deviation per subject
- 4 visualizations in a dashboard:
  - Bar chart with error bars — average score per subject
  - Histogram with normal distribution curve
  - Scatter plot — Math vs Science with pass/fail coloring
  - Grouped bar chart — pass vs fail per subject

## Tech Stack
- Python
- NumPy — data generation and statistics
- Matplotlib — visualization
- Jupyter Notebook — interactive analysis

## How to run
1. Clone the repo
   git clone https://github.com/Deepanshu9650/student-score-analyser.git

2. Install dependencies
   pip install numpy matplotlib jupyter

3. Open the notebook
   jupyter lab analysis.ipynb

4. Run all cells

## Key concepts demonstrated
- NumPy array operations and random data generation
- Statistical analysis with axis operations
- Matplotlib subplots and dashboard layout
- Boolean masking and np.polyfit for trend lines
